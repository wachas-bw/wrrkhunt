# Batch 2 drafts

Pune digital agencies (30-70 staff) plus batch 1 leftovers. Every draft passed the copy
linter. Angle comes from audit evidence, never assigned by hand, and evidence-backed
angles outrank assumptions: BrandLoom leads with Interakt because that is a fact on
their site, not with a guess about their back office.

**Why agencies:** the only pool that needs the product twice, internally for staff
(attendance, leave, payroll, tasks) and commercially for client work (proposals,
contracts, invoices, one inbox per client). Also the only pool that can resell, which
is exactly the segment GoHighLevel takes. All Pune, so the local line is true.

Send 1:1 from wachas@wrrk.ai, plain text, 20/day max. See SEND-RUNBOOK.md.
